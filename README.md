# wireless-charging-for-ev-s
The Wireless Charging Station for Electric Vehicle (EV) using ESP32 is a smart and innovative project that enables contactless charging through wireless power transfer technology.The system is designed to eliminate the need for conventional charging cables by transferring electrical energy wirelessly between transmitter and receiver coils using electromagnetic induction. By integrating the ESP32 microcontroller, the project offers enhanced processing capability, wireless connectivity, real-time monitoring, and future IoT integration features, making it a modern solution for next-generation EV charging infrastructure.
The project utilizes an ESP32 microcontroller, wireless charging modules, ultrasonic sensors, LCD display, LED indicators, and power control circuits. The ESP32 acts as the central controller, managing the charging process and monitoring sensor inputs. Ultrasonic sensors detect the presence and alignment of the vehicle over the charging pad, ensuring efficient energy transfer. Once the vehicle is correctly positioned, the transmitter coil generates a magnetic field that induces current in the receiver coil, enabling wireless charging of the EV battery.

An LCD display provides real-time information such as charging status, vehicle detection, and system operation. LED indicators offer visual feedback for charging conditions and system health. The ESP32’s built-in Wi-Fi and Bluetooth capabilities can be extended for remote monitoring, smart charging control, mobile application integration, and cloud-based data analytics.

This project focuses on improving charging convenience, operational safety, energy efficiency, and sustainability. By removing physical charging connectors, it reduces maintenance costs, prevents connector wear and tear, and minimizes electrical hazards. The system demonstrates the practical application of embedded systems, IoT, wireless energy transfer, and smart mobility technologies in the rapidly growing electric vehicle sector.
